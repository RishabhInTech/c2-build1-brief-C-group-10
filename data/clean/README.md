# data/clean

What the notebooks write. Every file here is reproducible from data/raw by running the notebooks in order from a fresh kernel. If a file here cannot be regenerated, delete it.

## Brief C: finance-only clean tables

Run `python notebooks/_scripts/clean_brief_c.py --source-dir data/Build1_DataPack.zip --output-dir data/clean/brief_c` with the approved full local data pack. This produces invoices, gateway payment attempts and settlements, retaining all rows and adding source provenance. `profile.json`, `input_clean_rejected.csv`, `issues.csv`, and `decisions_log.csv` are regenerated by the script. Brief C row-level `.csv` and profile `.json` files are Git-ignored; commit the cleaning code and aggregate profile outputs under `outputs/brief_c/`, not the finance records. The repository's `data/raw/` booking sample does not contain the finance pack.
